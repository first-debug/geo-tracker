# Описание директорий
- build - здесь лежат все файлы создаваемые в процессе компиляции и сборки. Их трогать не нужно.
- configs - здесь храняться разнообразные файлы конфигурации приложения.
- models - здесь находятся все файлы, которые необходимы для использования моделей: веса, модель в формате onnx, готовый engine для TenserRT.
